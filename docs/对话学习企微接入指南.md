# 对话学习企微接入配置指南（管理员自助）

> 服务端已就绪（里程碑 7）；本指南是你在企微后台要做的事。
> 端点均在中控服务上：默认 `http://<中控地址>:8600`

---

## 一、服务端已就绪的端点

| 端点 | 方法 | 用途 |
|------|------|------|
| `/api/dialog/wecom/callback` | GET | 企微回调 URL 验证（回显 echostr） |
| `/api/dialog/wecom/callback` | POST | 接收消息 → 内存缓冲（**原文不落库**） |
| `/api/dialog/refine` | POST | 手动触发提炼 → 候选进模板草稿区 |

连通性自测（本机）：

```bash
curl "http://127.0.0.1:8600/api/dialog/wecom/callback?echostr=ping"
# 期望返回纯文本: ping

curl -X POST http://127.0.0.1:8600/api/dialog/wecom/callback \
  -H "Content-Type: application/json" \
  -d '{"from":{"name":"自测"},"chat":{"chat_id":"test","name":"自测群"},"msgtype":"text","text":{"content":"测试消息"},"timestamp":1789000000}'
# 期望: {"ok":true,"buffered":1}

curl -X POST http://127.0.0.1:8600/api/dialog/refine -H "Content-Type: application/json" -d '{"min_messages":1}'
```

## 二、中控侧配置（server/.env）

```ini
# 不配任何一项 = 明文模式（本地/测试用）
YUANZHU_WECOM_TOKEN=            # 企微后台生成的 Token（验签用）
YUANZHU_WECOM_AES_KEY=          # 企微后台生成的 EncodingAESKey
YUANZHU_WECOM_CORP_ID=          # 企业 ID
YUANZHU_WECOM_ALLOWED_CHATS=    # 授权群 chat_id 白名单，逗号分隔；留空=全收
```

> ⚠️ 配了 `AES_KEY` 后当前版本仍走明文通道（AES 验签解密挂账中）——
> 接真实企微前先保持留空，或等 AES 通道补上。**自建转发/会话存档导出不受影响**。

## 三、企微后台配置步骤

1. **企业微信管理后台** → 应用管理 → 创建自建应用
2. 接收消息 → 设置 API 接收：
   - URL：`http://<中控IP>:8600/api/dialog/wecom/callback`（需公网/可信 IP）
   - Token / EncodingAESKey：随机生成后填入中控 `.env`
3. **可信 IP 白名单**：中控出口 IP 加入应用的可信 IP 列表（企微硬性要求）
4. 群机器人方式（备选）：若用群机器人回调，转发器把消息 POST 成第二节的消息 JSON 形态即可

## 四、降级路径（无企微权限时）

spec 预案：手动导出聊天记录文件上传（同一提炼管线）。实操：

```bash
# 把导出的消息按 JSON 形态逐条 POST 进回调端点，再触发 refine
python -X utf8 your_export_script.py   # 转换器可后补
```

## 五、合规边界（已实现，改前必读）

- 消息原文**只进内存环形缓冲**（2000 条上限），服务重启即清空
- DB 中无任何消息表（有测试断言看守：`test_no_message_persisted`）
- 提炼产物（工作流候选）落库时标注 `layer: 协同层`（诚实边界，H4 试验燃料）
- 授权群白名单生效后，非白名单群消息静默跳过
