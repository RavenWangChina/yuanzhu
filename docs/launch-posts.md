## A 版 → V2EX 分享创造

**标题：**

[分享] 做了个开源工具：AI 的写操作先暂存，人批准才生效（MCP 协议原生）

**正文：**

团队里用 Claude/Codex 这类 agent 干活，最怕的不是它不够聪明，是它太"勤快"——让它改个配置，它顺手把不该动的也改了；让它整理数据，它直接写进生产库。

所以我做了**元铸工坊（SOSOFAST）**：一个给 AI 加"操作冻结"的治理层。核心就一条规则：

> **AI 提议，人拍板。**

具体做了三件事：

**1. Staged writes——AI 的每个写操作先暂存**
AI 调用任何写动作（建对象/改数据/发通知），先进待审队列，展示它想干什么、动哪些字段、改前值是什么。你批准才落库，拒绝就丢弃。读操作不受限。审批权永远不会回流给 AI 自己。

**2. 一句话铸造工作流**
把你的例行工作描述给 AI（比如"我每周五要收集各小组进展汇总成周报"），它生成一个四段式模板：对象模型 + 动作库 + 工作流 + **评测集**。上架前过三道质量门：结构校验 → 工作流冒烟测试 → 评测守门。数据流不通的模板上不了架。

**3. 三记忆推衍**
行为日志（你干了什么）+ 知识库（沉淀了什么）+ 模板库（会了什么）交叉分析，主动提议："你连续三天在做同类的事，要不要铸成工作流？"

技术上的事：
- MCP 协议原生，已进官方 MCP Registry（io.github.RavenWangChina/yuanzhu）
- Claude Code 插件市场可装：`claude plugin marketplace add RavenWangChina/yuanzhu`
- Python 后端（FastAPI + SQLAlchemy），161 个测试，AGPL-3.0
- 还在 0.1.x 技术验证期，请以"尝鲜"预期来用

快速体验：

```
pip install yuanzhu
yuanzhu-server
```

然后浏览器打开 http://127.0.0.1:8600，README 里有 16 秒的 GIF 演示。

GitHub：https://github.com/RavenWangChina/yuanzhu

欢迎拍砖——尤其想听"你们团队不敢让 AI 碰什么"的真实场景，这决定了我下一步做什么。

## B 版 → 即刻（动态，配 2-3 张图）

**正文：**

我用一个工具，开发了它自己 🔨

三个月前想做个"把日常工作铸成 AI 工作流"的东西，然后发现：开发它的过程本身就是"把日常工作铸成 AI 工作流"——于是它成了自己的第一个用户。

这个工具叫**元铸工坊**，干的事一句话：**AI 提议，人拍板。**

→ 你说"我每周五要汇总各组周报"
→ AI 铸出一个工作流模板（还自带评测集，数据流不通不给上架）
→ 运行时 AI 的每个写操作先暂存，你批准才生效

最爽的瞬间是它第一次"自举"成功：用它自己的模板管理它自己的开发任务，待审中心里躺着 AI 提交、等我拍板的场景，就是产品的全部意义。

开源了（AGPL），MCP 协议原生，已进官方 MCP Registry，Claude Code 里两行命令就能装：

```
claude plugin marketplace add RavenWangChina/yuanzhu
claude plugin install yuanzhu@yuanzhu
```

GitHub 搜 RavenWangChina/yuanzhu，README 有 16 秒 GIF。

还在很早期（0.1.x），欢迎来当第一批用户，你的使用场景会直接变成它的开发需求。
