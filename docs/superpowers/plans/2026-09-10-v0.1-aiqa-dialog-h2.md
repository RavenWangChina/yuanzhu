# 元铸工坊 v0.1 AIQA 模板、对话学习与 H2 测试实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现元铸工坊 v0.1 的 AIQA 四段式模板、对话学习采集模块，并完成 H2 真人测试验证。

**Architecture:**
- AIQA 模板将 qa-knowledge 体系四段式化（对象/动作/工作流/评测集）
- 对话学习模块接入企微群消息流，提取高频工作模式
- H2 测试验证非技术者无指导 30 分钟完成真实任务

**Tech Stack:** Python 3.11+, FastAPI, Vue3, 企业微信 API

**Spec:** `docs/specs/v0.1-design.md` 第 3.2-3.3 节 + 第 6 节里程碑 6-8

**前置依赖:** 计划 1、计划 2 已完成

## Global Constraints

- **AIQA 模板规范**：四段式标准（ontology/actions/workflows/evals）
- **对话学习合规**：只处理已授权群，消息原文不落库
- **H2 验证标准**：无指导 30 分钟完成真实任务，求助 ≤2 次
- **时间处理**：时间权威源用 PowerShell
- **测试策略**：TDD + H2 真人测试录屏

**目标：** 将 AIQA 的 qa-knowledge 体系映射到四段式模板

**AIQA 对象模型：**
- `Module` - 测试模块
- `TestCase` - 测试用例
- `Bug` - 缺陷
- `Report` - 测试报告
- `Evidence` - 测试证据

**AIQA 动作库：**
- `CreateBug` - 创建缺陷
- `ResolveBug` - 解决缺陷
- `LinkEvidence` - 关联证据
- `RegisterModule` - 注册模块
- `CreateTestCase` - 创建测试用例
- `ExecuteTestCase` - 执行测试用例

**AIQA 工作流：**
- `archaeology-workflow` - 考古工作流
- `dual-testcase-workflow` - 双用例工作流
- `execution-workflow` - 执行工作流
- `report-workflow` - 报告工作流

## Task 18: 对话学习采集模块

**Files:**
- Create: `server/src/yuanzhu/dialog/__init__.py`
- Create: `server/src/yuanzhu/dialog/collector.py`
- Create: `server/src/yuanzhu/dialog/pattern_extractor.py`
- Create: `server/src/yuanzhu/dialog/models.py`
- Create: `server/tests/test_dialog_collector.py`

**目标：** 接入企微群消息流，提取高频工作模式

**核心逻辑：**
1. 企微群机器人回调 → 接收原始消息流
2. 存储到临时缓存（不落库原文）
3. 调用模型网关 → 提炼"高频工作模式候选"
4. 产出 = 工作流候选草案（staged 状态）
5. 人审后进入模板库

**合规约束：**
- 只处理已授权群
- 消息原文不落库（只落提炼产物）
- 或按企业配置保留期限

## Task 20: H2 真人测试

**Files:**
- Create: `docs/test-reports/h2-test-report-template.md`
- Create: `server/tests/test_h2_scenario.py`

**目标：** 验证非技术者无指导 30 分钟完成真实任务

**测试流程：**
1. 找一位非技术同事
2. 只发一个控制台链接
3. 观察完成"审批一个 staged 动作+触发一个模板任务"
4. 录屏 + 求助计数
5. 记录失败模式

**通过标准：**
- 求助 ≤ 2 次
- 30 分钟内完成
- 全程不碰代码不碰命令行
