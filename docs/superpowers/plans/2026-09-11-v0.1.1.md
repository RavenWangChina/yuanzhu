# v0.1.1 实施计划（打磨版 + 并行 agent）

**Goal**: 开箱体验毛刺清零 + forge 闭环补全 + 问答直达 + 引擎真并行（主从对话地基）

**范围**（用户裁决 2026-09-11）：A 启动提速 / B evals 副作用 / D 估费 / E 枚举中文化 / F 草稿转正 / G 问答直达 / H 并行 agent

## 任务分解（TDD）

### T1 (A) 启动提速
- `yuanzhu/__init__.py`: `os.environ.setdefault("LITELLM_LOCAL_MODEL_COST_MAP", "True")`（禁远程价格表拉取，10s+→秒级）
- 验证：服务启动计时对比

### T2 (D) 估费真值（依赖 T1 的本地价格表）
- `gateway/proxy.py` 的 acompletion 后：`litellm.completion_cost(completion_response=resp)` try/except 记 0
- 测试：mock response 带 usage，断言 estimated_cost ≥ 0 且调用不炸

### T3 (B) evals 副作用隔离
- `EvalsRunner.run_template` 结束时清理：删除本次跑出的 `eval-` 前缀对象（title/question/takeaway 匹配）；exec 记录保留（审计）
- 测试：evals 全过 + 库中无 eval- 残留

### T4 (E) 枚举值中文化（显示层）
- `web/src` 公共 `labels.ts`：severity/status 枚举→中文（major→较重 等）；Staged/Templates/Ask 页使用
- 不改存储值（英文是数据契约）

### T5 (H) 引擎并行步骤组（核心，风险最高）
- **DSL**：steps 数组中允许 `{"parallel": [step, step, ...]}` 组——组内 asyncio.gather 并发，全部完成后继续
- **并发安全**：AsyncSession 非并发安全——并行 ai_step 各自用 `async_session_factory()` 独立 session（计量各自写）；主流程 session 不进并行组
- deep-answer 改造：view-a/view-b 改并行（B 从"反驳A"改为"独立识别风险与替代路线"——双盲视角，对抗移到 audit 步）
- 测试：并行组两步并发执行（计时/顺序断言）+ 各自计量落库不炸

### T6 (F) 草稿转正闭环
- forge 时把 evals 报告存入 `Template.manifest_json.last_evals_report`
- API：`POST /api/templates/reload {name}` = 重读目录 + 注册 + 重跑 evals（复用 forge 后半段，抽公共函数）
- Web：draft 卡片显示失败用例 + 「重跑评测」按钮 + 目录路径提示
- 测试：draft reload 后全过→published

### T7 (G) 问答直达
- `web/src/views/Ask.vue`：输入框 → run deep-answer → 六步进度（简单：跑完展示）→ 最终答案展示 + 「采纳」按钮（approve save exec）
- 路由：`/` 重定向改 `/ask`；导航首项「深度问答」
- 构建+实测

## 顺序
T1→T2→T3（后端小件）→ T5（引擎，先于模板改造）→ deep-answer 并行化 → T6 → T4+T7（前端一批）→ 回归+实测+文档+推送
