# v0.2.0「First 5 Minutes」实施方案

> 立项：2026-09-15 · 主题：接住宣传流量——从安装到 aha 的 5 分钟路径
> 输入：外部实测报告（安装卡死）+ 增长调研（转化漏斗断在"试用"环）

## 侦察结论（改方案的关键事实）

- litellm 在 `acompletion` 主链路（不只估费）→ 不能只挪 extras，需内置直连层
- ProviderRegistry 已解析出 api_base/api_key/model（litellm kwargs 形态）→ 直连层有现成输入
- Web 首页是 /ask（Chat.vue）→ 引导层挂 App 级
- 内置模板 6 域在 `src/yuanzhu/templates/` → 演示域同构新增

## 四项改造

### 1. 安装硬化：litellm 可选化
- `pyproject.toml`：litellm → `[project.optional-dependencies] gateway`
- `proxy.py` 加 `_openai_direct()`：httpx 直连 OpenAI 兼容端点（fastapi 已带 httpx）
- `acompletion` 路由：有 api_base 的 OpenAI 兼容 → 直连；litellm 特殊前缀 → 需 litellm（未装给安装提示）
- 估费：litellm 缺失 → cost=0（已是兜底行为）

### 2. `yuanzhu-demo` 一键体验
- 新入口 `yuanzhu-demo`（`yuanzhu.demo:main`）
- 流程：起服务（线程 uvicorn）→ health 就绪 → 灌演示数据 → 开浏览器 → 打印三步体验路径

### 3. 新用户引导流
- 后端 `GET /api/first-run`：库空判定（对象数 0）
- 前端 Welcome 覆盖层（App 级组件 + localStorage 已读标记）：三步 checklist

### 4. 预置演示域
- `templates/demo/`：DemoTask 对象 + 动作（staged）+ 工作流
- 种子数据由 demo.py 灌（不污染正常启动路径）

## 顺序（TDD）
1 → 2 → 4 → 3（引导层依赖演示内容）

## 验收（环节 5 用）
- 新 venv `pip install dist/*.whl`（无 litellm）→ `yuanzhu-demo` → 30 秒内浏览器见到有数据的界面
- 161 旧测试 + 新测试全绿
- 现有 litellm 路径（已装环境）行为不变
